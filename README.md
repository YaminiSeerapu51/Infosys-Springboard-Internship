# 🌍 Interactive Data Visualization of Global Travel & Holidays

A complete data analytics and visualization project developed during the **Infosys Internship 6.0 (B1)**.  
This project focuses on analyzing worldwide travel and tourism data to uncover patterns, economic impact, and seasonal insights through interactive dashboards.

---

## 🚀 Project Goals

- Transform raw tourism data into meaningful visual insights
- Compare **domestic vs international travel trends**
- Identify **top-performing travel destinations**
- Analyze how tourism impacts **GDP, revenue & unemployment**
- Create a user-friendly and interactive Power BI dashboard

---

## 🔎 Key Findings from Visualizations

✔ 34.68M passengers analyzed  
✔ USA, China & UK among **top travel destinations**  
✔ Tourism revenue peaks between **2015–2018**  
✔ Seasonal peak during **Summer & Autumn**  
✔ Direct correlation between tourism arrivals & economic growth
